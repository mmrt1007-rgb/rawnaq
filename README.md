# رونق · Rawnaq

واجهة رئيسية عربية أنيقة لشاشات أندرويد TV (٩ إلى ١٦)، بهوية أهل البيت (ع): ثيمات ملكية ليلية ونهارية، طقس حي سينمائي، مواقيت الصلاة، ملفات العائلة والأطفال، وتحديث تلقائي من GitHub.

> **كان اسمه «الحافظ».** أول مرة تشغّل `install.bat` على شاشة بيها الحافظ، ينقل نسخه الاحتياطية وخلفياته لرونق، ورونق يرجّع إعداداتك وترتيبك وحده بأول تشغيل، وبعدها يشيل التطبيق القديم. مفتاح التوقيع القديم (`hafidh_keys`) ينستخدم نفسه.

## التنصيب السريع (أي شاشة، أي عنوان)
شغّل `install.bat` واكتب **عنوان IP الشاشة** (من الشاشة: الإعدادات ← الشبكة ← الواي فاي ← عنوان IP)، أو اختار رقمها من القائمة.
- السكربت يربط على **نفس العنوان اللي كتبته فقط**، وكل أمر يروح له بالتحديد، فما يمكن ينصب على شاشة ثانية بالغلط حتى لو بالشبكة أكثر من جهاز.
- يجرب الربط بثلاث طرق تلقائياً: المنفذ 5555 (أندرويد ٩–١٠)، كيبل USB (يحوّله للشبكة بنفسه)، ثم "تصحيح الأخطاء اللاسلكي" بأندرويد ١١+ (يلكاه تلقائياً أو يطلب رقم المنفذ ورمز الإقران المكتوبين على الشاشة مرة وحدة).
- يعالج أخطاء التنصيب بنفسه: توقيع قديم مختلف، مساحة قليلة، انقطاع الاتصال، وأخيراً ينسخ الملف للشاشة وينصبه منها.
- يتأكد إن الجهاز اللي جاوب هو نفس العنوان، ويعرض الماركة والموديل ونسخة أندرويد قبل التنصيب، ويحفظ الشاشة بالقائمة للمرات الجاية (`tvs.txt`).
- إذا adb مو موجود بالحاسبة، ينزله بنفسه.
- تكدر تكتب أكثر من عنوان مفصولة بفاصلة، أو `A` للكل، أو عنوان مع منفذ مثل `192.168.1.20:41231`.

اختصارات: تگدر تسوي ملف `.bat` لكل شاشة بعنوانها (مثل `install.bat -TvIp 192.168.1.20`). هالملفات وقائمة شاشاتك `tvs.txt` تبقى على حاسبتك وما تنرفع لـ GitHub.

## شنو بيه (الإصدار ٢)
- **محرك ثيم كامل:** كل لون بالثيم النهاري والليلي قابل للتعديل بالريموت (ألوان جاهزة + ضبط دقيق للدرجة والتشبع والإضاءة)، مع ٦ ثيمات جاهزة.
- **أكثر من ٤٠ خط عربي مضمّن** داخل التطبيق (الأميري، الرقعة، الكوفي، النسخ، النستعليق، القاهرة، تجوال، المراعي...) تنزل من Google Fonts وقت البناء وتشتغل بدون إنترنت.
  - خط مستقل للواجهة، للعناوين، للساعة، ولشاشة السكون.
  - حجم خط عام بدقة ٥٪، وسُمك النص.
- **٤ تخطيطات للتطبيقات:** صف أفقي، شبكة عمودية، صفحات، عمود جانبي — مع عدد الأعمدة والصفوف.
- **المربعات:** ٣ أنماط (بانر ١٦:٩، مربع، دائري)، الحجم، الاستدارة، المسافات، التكبير وإطار التركيز والظل، الأسماء (دائماً / عند التركيز / بدون) وحجمها.
- **الواجهة:** إظهار وإخفاء كل عنصر، أحجام الساعة والتاريخ، نظام ١٢/٢٤، الهوامش، وخلفية (لون، تدرج، فنية، صورة).
- **شاشة السكون:** خلفية (أسود، لون، تدرج، ٦ تصاميم فنية، صورة 4K، أو عرض صور متتابع بحركة تقريب بطيئة)، مكان العناصر، كل عنصر يظهر أو يختفي، خطوطها وأحجامها وألوانها مستقلة، وتحريك بطيء لحماية الشاشة.
- **الخلفيات 4K:** من مجلد `wallpapers` بالحاسبة (السكربت ينسخها)، أو استيراد من فلاشة USB. الصور تُفك بدقة الشاشة الفعلية بالضبط.
- **مواقيت الصلاة:** حساب فلكي محلي لأي يوم (العمارة افتراضياً + ٩ مدن عراقية)، الإمساك والفجر والشروق والظهر والغروب والمغرب ومنتصف الليل، مع تعديل بالدقائق لكل وقت حتى يطابق تقويم الأنصاري، والوقت القادم مع عد تنازلي — بالواجهة وبشاشة السكون.
- **مكان ذكي لعناصر شاشة السكون:** تلقائي (يحلل الصورة ويختار أهدأ زاوية)، أو ٩ مواضع جاهزة، أو تحديد دقيق بخطوات ٥٪. والألوان تلقائية حسب إضاءة الصورة تحت الساعة، أو يدوية.
- **تجديد الخلفيات تلقائياً:** يحافظ على ٢٠–٦٠ صورة 4K ويجدد ثلثها كل فترة تختارها.
- **فرض الوضع العرضي** على تطبيقات الهاتف الطولية، و**إيقاف شاشة سكون النظام** حتى تشتغل شاشة رونق فقط.
- **تنقل بترتيب القراءة:** يسار = التطبيق التالي، وبنهاية الصف ينزل للصف اللي تحته، وبآخر تطبيق يرجع للأول. يمين بالعكس. نفس المنطق بكل الشبكات (التطبيقات، الخلفيات) وبين الصفحات.
- **زر الهوم وأنت بالواجهة:** يسكّر أي شاشة مفتوحة ويرجع لأول تطبيق.
- **الإعدادات:** ◀ أو موافق يدخل للخيارات ويرجع لآخر خيار كنت عليه، ▶ أو رجوع يرجع للقسم نفسه. التركيز ما يقفز لما تظهر أو تختفي خيارات.
- **نمطين للواجهة:** كلاسيكي أنيق، أو زجاج مغبش حقيقي (قوة التغبيش والكثافة قابلة للتعديل). التبديل لحظي وبدون ما تضيع أي إعداد — واختصار: ضغطة طويلة على زر الإعدادات.
- **محرر ترتيب شاشة السكون:** مباشر على الشاشة نفسها؛ تختار أي عنصر (الساعة، اليوم، التاريخين، الوقت القادم، المواقيت، الطقس، العد التنازلي، النص الخاص) وتحركه بالأسهم بخطوات دقيقة، وتغير حجمه أو تخفيه. الألوان التلقائية تنحسب لكل عنصر حسب الصورة تحته.
- **عد تنازلي لمناسبة** (رمضان مثلاً) كعنصر بشاشة السكون.
- **الستايل السينمائي (مستوحى من أجواء أبل تي في):** خلفية أو عرض صور يملأ الشاشة، ساعة صغيرة أنيقة بالزاوية، تطبيقات بانر عائمة بالأسفل تكبر مع ظل ولمعة ضوء عند التركيز، وزجاج مغبش. تفعيل بضغطة ورجوع للإطلالة السابقة بضغطة.
- **شاشة سكون أنيقة سينمائية (الافتراضية):** تظليل ناعم، ساعة كبيرة بالزاوية مع خط فاصل، التاريخان بسطر واحد، الطقس بالزاوية العليا، والمواقيت خط زمني يمتد بعرض الشاشة والوقت القادم يتوهج مع العد التنازلي.
- **يشتغل على أندرويد ٩ إلى ١٦** وكل أحجام ونسب الشاشات (16:9، 21:9، 16:10…): العرض ثابت والارتفاع يتبع نسبة الشاشة، فالواجهة تملأها بدون أشرطة أو قص.
- **أداء تلقائي حسب الجهاز:** على الأجهزة الضعيفة (أندرويد ٩ أو ذاكرة قليلة) يشتغل وضع خفيف بدون تغبيش حي ولا حركات مستمرة. يتغير من عام والنظام ← الأداء.
- **الإعدادات بمنطق القفل:** ▲▼ بين الأقسام، موافق يدخل ويقفل داخل خيارات القسم (الأسهم ما تطلعك برا). موافق على أي خيار يفتح قائمته وتبقى مفتوحة تختار براحتك، والقيم الرقمية تتعدل بالأسهم. **رجوع ١:** للقسم. **رجوع ٢:** لأول قسم. **رجوع ٣:** خروج للواجهة.
- **الواجهة ترجع لأول تطبيق** كل ما ترجع لها: من الإعدادات، من أي شاشة، بعد تشغيل تطبيق، بزر الهوم، أو بزر الرجوع.
- **ثلاث أنماط رسمية للثيم:** كلاسيكي، زجاج مغبش، سينمائي (ستايل Apple TV) — من المظهر والألوان ← نمط الواجهة، أو ضغطة طويلة على زر الإعدادات تبدّل بينها.
- **كل نمط له ترتيبه الخاص:** الكلاسيكي والزجاجي والسينمائي، كل واحد يحفظ ترتيب التطبيقات والواجهة وشاشة السكون لحاله. تعدّل نمط وتنتقل لغيره وترجع، تلكاه مثل ما تركته. وبكل قسم زر "ترتيب النمط الأصلي".
- **ترتيب Apple TV بتطبيقاتك:** بالنمط السينمائي، مساحة واسعة للخلفية بالأعلى يظهر بيها اسم التطبيق المحدد والتاريخ والوقت القادم، وتحتها شبكة تطبيقاتك (٥ أعمدة افتراضياً). النزول للصفوف التالية يرفع الشبكة بنعومة، والرجوع للصف الأول يرجع المساحة.
- **اللوحة السريعة** (زر اللوحة بأعلى الواجهة، يمين زر الإعدادات): تنزلق من جانب الشاشة فوق الواجهة وبيها: حالة الشبكة وعنوان الـ IP، مستوى الصوت، الذاكرة مع زر تنظيف، التخزين، مؤقت الإطفاء (١٥ دقيقة إلى ٣ ساعات، ويطفي الشاشة فعلياً)، نمط الثيم، نهاري/ليلي، تشغيل شاشة السكون، وإعدادات الواجهة والنظام. الأسهم تتنقل وتلتف، موافق يفتح، رجوع يسكّر.
- **نظام تصميم فيكما:** https://www.figma.com/design/TyAFp9w6J2vaMWq4toU55S — الألوان (أوف وايت نهاري · زمردي ليلي)، الخطوط، أيقونات Lucide، الثيمات الملكية الستة، وكل الشاشات بمقاس 1920×1080 بالوضعين.
- **الثيمات الملكية:** الزمرد الملكي (الافتراضي)، العبّاسي، الأندلسي، الذهب الأسود، اللؤلؤي — كل ثيم بألوانه النهارية والليلية وخطوطه الثلاثة (العناوين، النصوص، الساعة)، وكل لون وخط يتعدل بعده.
- **أيقونات Lucide** بنفس رسم فيكما (ISC License).
- **أربعة أنماط:** كلاسيكي، زجاج مغبش، سينمائي (ترتيب Apple TV)، شرائط عصرية — كل نمط بترتيبه الخاص.
- **كل الأحجام محسوبة تلقائياً** على لوحة 1920×1080 تتكيف مع أي شاشة، بدون قص أو تداخل.
- **شاشات فيكما الأربع الجديدة مطبقة:** كل التطبيقات (✓ للظاهر بالواجهة والباقي شفاف)، الخلفيات (شارة 4K، شارة الاستعمال الحالي، ولوحة خيارات بالزاوية)، تخصيص التطبيق (لوحة عائمة بأيقونات + معاينة مكبّرة مباشرة)، ومحرر شاشة السكون (خطوط إرشاد، إطار متقطع للعناصر وذهبي للمحدد مع اسمه ونسبة حجمه، وشريط تعليمات ينزل للأسفل إذا العنصر فوق).

## البناء التلقائي على GitHub والتحديث الذاتي

مرة وحدة:
1. شغّل **install.bat** مرة (يبني ويحفظ مفتاح التوقيع بـ `%USERPROFILE%\rawnaq_keys` — خذ منه نسخة على فلاشة).
2. شغّل **github-setup.bat**: ينصّب Git وGitHub CLI إذا ناقصين، يسجل دخولك، ينشئ مستودع عام `rawnaq`، يرفع المشروع، يحفظ مفتاح التوقيع كـ Secret، وينشر الإصدار الحالي.
3. شغّل **install.bat** مرة ثانية حتى رونق بالستريمر يعرف رابط التحديث.

بعدها كل تحديث:
1. ارفع الرقم بـ `pubspec.yaml` (مثلاً `version: 3.7.1+12`) واكتب الجديد بـ `release-notes.txt`.
2. شغّل **github-setup.bat** → GitHub يبني (حوالي ٨ دقائق) وينشر الـ APK و`update.json`.
3. الستريمر يفحص يومياً ويطلع لك «تحديث جاهز» — تثبّته بضغطة وتوافق.

- كل رفع للكود يُبنى تلقائياً ويوقف عند أي خطأ برمجي (صفحة Actions)، فالأخطاء تنكشف قبل ما توصل للشاشة.
- **مفتاح التوقيع ثابت**: نفس المفتاح بحاسبتك وبـ GitHub، فالتحديث يتثبت فوق القديم بدون حذف ولا ضياع إعدادات. إذا ضاع المفتاح ما يتحدث التطبيق إلا بحذفه — لذلك احفظ نسخة.
- المستودع لازم يكون **عام** حتى الستريمر ينزّل التحديث بدون كلمة سر (المفتاح نفسه ما ينرفع، يبقى Secret مشفر).

- **العلوي** — أمير المؤمنين (ع): ذهب القبة ولازورد
- **الفاطمي** — سيدة نساء العالمين (ع): لؤلؤ وورد
- **الحسني** — كريم أهل البيت (ع): زمرد وفضة
- **الدر الحسيني** — سيد الشهداء (ع): عقيق وذهب

## الجديد بالإصدار ٣٫٧ — ما بعد واجهة كوكل (فيكما صفحة 11)

- **زر «إعدادات الجهاز»**: كبسولة ذهبية بأيقونة monitor-cog بأعلى الواجهة، وشريط ذهبي باللوحة السريعة، تفتح إعدادات Google TV نفسها. ترس رونق الأخضر يبقى لإعدادات الثيم («إعدادات رونق»).
- **أزرار الواجهة الجديدة**: البحث، الجرس برقم التنبيهات، الملف (العائلة/الأطفال/الضيف) — كلها تنطفي وتشتغل من الإعدادات ← أزرار الواجهة.
- **حارس الواجهة**: خدمة إمكانية وصول صغيرة ترجّع رونق خلال ثانية إذا تحديث النظام رجّع واجهة كوكل. install.bat يفعّلها.
- **البحث**: بالتطبيقات المنصّبة لحظياً مع كل حرف، وبحث كوكل والبحث الصوتي، و«آخر ما فتحته».
- **مركز التنبيهات**: تنبيهات رونق (الأذان، النسخ، التحديث، الحارس، المناسبات) وتنبيهات التطبيقات (بصلاحية يعطيها install.bat).
- **التحديث التلقائي**: فحص يومي لملف تحديث على رابط تحدده، تنزيل وتثبيت بضغطة (النظام يطلب تأكيدك)، ونسخة احتياطية قبله. إذا رونق منصّب من Google Play فالتحديث من المتجر.
- **ملفات العائلة والأطفال**: ملف الأطفال بتطبيقات مختارة، وقت مشاهدة يومي، وقت نوم، وشاشة قفل لطيفة بالرمز.
- **التلفزيون والطاقة**: قابس ذكي Shelly/Tasmota — لما الستريمر ينام تنقطع كهرباء التلفزيون بعد ثوانٍ، ولما يصحى ترجع.
- **العرض والصوت، زر النجمة، المنزل الذكي، التقويم الهجري والمناسبات، المحتوى اليومي، الأداء والحجم.**
- كلها بالإعدادات ← الشاشة والنظام ← «الستريمر بعد واجهة كوكل».
- ملف التحديث (update.json) مثال: `{"version":"3.7.1","apk":"https://…/app-release.apk","notes":["…"]}`

## إطفاء الشاشة من الستريمر (cec-fix.bat)

إذا الستريمر ينام والتلفزيون يبقى شغّال بشاشة زرقاء:
1. شغّل `cec-fix.bat` واكتب IP الستريمر.
2. السكربت يقرأ حالة HDMI-CEC، ويجرب كل التركيبات (وضع التحكم × إصدار CEC 1.4/2.0 × نوم الستريمر أو أمر طاقة التلفزيون)، ويسألك بعد كل تجربة هل انطفت الشاشة فعلاً.
3. أول تركيبة تشتغل تنحفظ على الستريمر.
4. إذا الشاشة ما تستجيب لأي أمر إطفاء: قابس ذكي Shelly أو Tasmota على كهرباء التلفزيون، والسكربت يختبره (إطفاء CEC ← ١٠ ثوانٍ ← قطع الكهرباء ← رجوعها).
5. كل النتائج بمجلد `cec`.

## الجديد بالإصدار ٣٫٦ — الاستمرارية والموثوقية (فيكما صفحة 10)

- **شاشة الإقلاع:** الشعار وتقدّم التحميل (الإعدادات ← التطبيقات ← الخلفيات) تطلع فوراً — ما تبقى الشاشة سوداء، وبعد ٨ ثوانٍ كحد أقصى تفتح الواجهة.
- **الوضع الآمن:** إذا التطبيق انفتح ٣ مرات خلال دقيقتين (يطيح ويرجع) يفتح بدون حركة ولا زجاج، ويعرض آخر خطأ، ويعطيك: تشغيل آمن، استعادة آخر نسخة، إعدادات النظام، حفظ السجل للفلاشة، أو إعادة الضبط.
- **النسخ الاحتياطي:** نسخة يومية تلقائية (آخر ٧)، نسخة الآن، تصدير واستيراد بالفلاشة، واستعادة أي نسخة بضغطة.
- **صحة النظام:** الذاكرة، التخزين، الشبكة، سلاسة الواجهة (إطار/ثانية حقيقية)، أعطال الأسبوع، والخلفيات — مع تنظيف ذكي وحفظ تقرير.
- **تنبيه الأذان:** ينزل من أعلى الواجهة قبل الأذان (٥–٢٠ دقيقة) ووقت الأذان، ويختفي وحده بدون ما يسرق التركيز.
- **جدول التشغيل والإطفاء:** إطفاء تلقائي بوقت تختاره، تنبيه قبله بدقيقة، ينتظر إذا فيديو شغّال، وساعات هدوء بلا شاشة سكون ولا تنبيهات.
- **التحديثات:** الإصدار ووقت آخر تحديث وما الجديد، ونسخة احتياطية قبل التحديث.
- **معالج الإعداد الأول:** الثيم، المدينة، التطبيقات، الشبكة — لأول تشغيل فقط (اللي يرقّي ما يطلعله).
- كلها بالإعدادات ← الشاشة والنظام ← «الحماية والاستمرارية»، وتنبيه الأذان بقسم المواقيت.

## الجديد بالإصدار ٣٫٥ — الثيمات الملكية الموسّعة

- **١٦ ثيماً ملكياً** (منها: الياقوتي، النجفي، البابلي، المرجاني، البنفسجي الملكي). لكل ثيم ألوانه النهارية والليلية، خطوطه الثلاثة (عناوين، نصوص، ساعة)، **وترتيب واجهته الملكي** وشكل أيقوناته وخلفيته — كلها مرسومة بفيكما صفحة 09.
- خيار «تطبيق الترتيب الملكي مع الثيم» بالمظهر: أطفيه إذا تريد يتغير اللون والخط بس.
- **٣ أشكال أيقونات جديدة:** محراب، ثُمانية، مشطوفة (صار المجموع ٩).
- **نمط جديد «الناعم العصري»**: ترقية فيكما الشاملة كنمط تختاره (مو تغيير شامل): حواف متصلة لكل البطاقات والصفوف واللوحات، ظلال هادئة، خلفية أورورا، وانتقال تكبير هادئ.

## الجديد بالإصدار ٣٫٤ — الواجهة الحديثة

- **نمط جديد افتراضي: «الحديث»** (فيكما صفحة 08، نهاري وليلي): شريط تنقل بالوسط، عمود الوقت والتاريخ والطقس والمواقيت يمين، بطاقة بارزة كبيرة للتطبيق المحدد يسار، وشريط مربعات ناعمة ترتفع بظل عند التركيز.
- **خلفية «أورورا»**: ثلاث هالات ضوء بألوان الثيم، تُرسم مرة وحدة — بدون صور ثقيلة ولا تغبيش، فالواجهة أخف وأسرع بكثير. الأوف وايت النهاري صار هادئ ودافئ.
- **أداء**: الواجهة الحديثة بدون طبقات تغبيش متكررة، صور البطاقة البارزة تُفك بحجم العرض فقط، والتطبيق يُبنى لمعالجات ARM فقط (حجم أصغر وتشغيل أسرع).
- كل لوحات فيكما الجديدة صار إلها نسخة **نهارية** (أوف وايت) بجانب الليلية: الأيقونات، الحركة (مع العرض التفاعلي)، الخطوط، كتالوج كل الخيارات، وترتيبات المرسى والبطاقة البارزة واللوحتين.
- التحديث ينقل الواجهة للنمط الحديث مرة وحدة، وكل الأنماط الثانية تبقى بالإعدادات ← المظهر ← نمط الواجهة.

## الجديد بالإصدار ٣٫٣

- **شكل الأيقونات بالواجهة:** حادة، مستديرة، ناعمة (مثل iOS)، دائرية، كبسولة، ورقة — مع نوع البطاقة (بانر/مربعة/دائرة)، خلفية الأيقونة (الأصلية/هادئة/أحادية ذهبية)، وتأثير التركيز (إطار ذهبي/توهج/رفع وظل/تكبير). كلها ببطاقات معاينة حقيقية بالإعدادات ← التطبيقات والأيقونات.
- **قسم جديد: الحركة والسرعة:** أسلوب الحركة (ناعمة، نابضة، أنيقة، سريعة، بدون) بمعاينة متحركة، سرعة الحركة، انتقال الشاشات (تلاشي/انزلاق/تكبير)، والأداء.
- **أزواج خطوط جاهزة:** ملكي، تراثي، عصري، هادئ، حادّ، نسخي — تطبّق خط العناوين والنصوص والساعة مرة وحدة.
- **معاينة لكل خيار:** المعاينة الحيّة صارت تتبع الخيار المحدد نفسه (لون معيّن، خط معيّن) مو بس القسم.
- بفيكما: صفحة 07 فيها لوحات الأيقونات والحركة (مع عرض تفاعلي Smart Animate) والخطوط، وكتالوج كامل لكل خيارات الإعدادات (١٨٠ خياراً تقريباً) كل واحد بمعاينته.

### إذا شفت تداخل أو تشوه بالرسم على شاشة معيّنة
شغّل **tv-check.bat** واكتب عنوان الشاشة. يجمع نوع الشاشة ونسخة أندرويد ومعالج الرسوم ومقاس الشاشة، ويصوّر واجهة رونق والشاشة اللي بيها المشكلة، بمجلد `tv-check`. ما يغيّر أي شي بالشاشة.

## إذا الشاشة علكت أو ما ظهر شي بعد التنصيب

شغّل **rescue.bat** واكتب عنوان الشاشة. خلال دقيقة:
1. يرجّع الواجهة الأصلية مال الشاشة ويطفي DNS حجب الإعلانات، فترجع الشاشة تشتغل طبيعي.
2. يشغّل رونق مرة وحدة ويسجّل سبب المشكلة الحقيقي (سجل الأعطال + صورة الشاشة) بمجلد `rescue`.
3. اضغط المجلد zip ودزه لـ Claude.

## الجديد بالإصدار ٣٫٢

- **اللوحة السريعة الجديدة** (مثل Google TV بأندرويد ١٤ بأسلوب رونق): تطلع على يسار الشاشة بهامش أنيق والواجهة خلفها مغبّشة.
  - ٨ بطاقات حقيقية: الشبكة، البلوتوث، حجب الإعلانات (AdGuard DNS لكل الجهاز)، عدم الإزعاج (يوقف شاشة السكون التلقائية)، الوضع نهاري/ليلي، مؤقت الإطفاء، شاشة السكون، تنظيف الذاكرة.
  - البطاقة المفعّلة تتلون بلون الثيم، وضغطة مطوّلة على موافق تفتح تفاصيلها مباشرة (الشبكة، المؤقت، الوضع والنمط، الذاكرة والتخزين).
  - شريط صوت: يمين ويسار للتعديل، موافق للكتم. زر إطفاء الشاشة وزر كل الإعدادات.
  - التنقل: أعلى وأسفل بين الصفوف، يمين ويسار بين العمودين، رجوع من التفاصيل للوحة ثم يسكّرها.
- **معاينة حيّة بالإعدادات** لكل الأقسام على يسار الشاشة: الثيمات تنعرض قبل التطبيق، المربعات الحقيقية، شاشة السكون الحقيقية مصغّرة، المواقيت، الخلفيات، التاريخ والطقس، الريموت، وغيرها — مع شرح الخيار المحدد وشنو يتأثر بيه.
- أقسام جديدة: **الريموت والتنقل**، **إمكانية الوصول** (حجم النص ١٠٠/١١٥/١٣٠٪، تباين عالٍ، إطار تركيز سميك، تقليل الحركة)، و**حول رونق** مع شاشة كاملة.

- نمطين جديدين: **البسيط الهادئ** (مرسى أيقونات بلا أسماء + ساعة فقط بالسكون) و**المجلة** (بطاقة بارزة + أسماء واضحة).
- حجب الإعلانات يحتاج صلاحية WRITE_SECURE_SETTINGS اللي يمنحها install.bat تلقائياً.

## ١. البناء على الحاسبة
المتطلبات: Flutter 3.27 أو أحدث، وAndroid Studio (حتى ينصب Android SDK).

افتح PowerShell داخل هذا المجلد وشغّل:
```powershell
.\setup.ps1
```
إذا طلع خطأ صلاحيات تشغيل السكربتات:
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```
بالنهاية يطلعلك مسار الملف: `%USERPROFILE%\rawnaq_build\build\app\outputs\flutter-apk\app-release.apk`

## ٢. الربط مع الشاشة
1. بالشاشة: الإعدادات ← الشبكة ← اعرف عنوان IP (مثل `192.168.1.25`).
2. الحاسبة والشاشة على نفس الواي فاي.
3. من الحاسبة:
```powershell
adb connect 192.168.1.25:5555
```
4. تطلع رسالة على الشاشة "السماح بتصحيح الأخطاء؟" ← اختار **سماح دائماً**.

> بأغلب شاشات أندرويد 9، تفعيل "تصحيح USB" يفتح المنفذ 5555 عبر الشبكة تلقائياً. إذا ما اشتغل، شوف الطريقة البديلة تحت.

## ٣. التنصيب
```powershell
adb install -r %USERPROFILE%\rawnaq_build\build\app\outputs\flutter-apk\app-release.apk
```

## ٤. جعله الواجهة الافتراضية
اضغط زر الهوم بالريموت. إذا سألك أي واجهة تريد، اختار **رونق** ثم **دائماً**.

إذا ما سألك:
```powershell
adb shell cmd package set-home-activity com.rawnaq/.MainActivity
```
إذا الواجهة الأصلية بقت ترجع، عطّلها مؤقتاً:
```powershell
adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell pm disable-user --user 0 اسم-الحزمة-الأصلية
```
للتراجع بأي وقت:
```powershell
adb shell pm enable اسم-الحزمة-الأصلية
```

## ٥. منع الإعلانات على مستوى الشاشة كلها
```powershell
adb shell settings put global private_dns_mode hostname
adb shell settings put global private_dns_specifier dns.adguard-dns.com
```
للتراجع:
```powershell
adb shell settings put global private_dns_mode off
```

## طريقة بديلة بدون ADB
1. انسخ ملف `app-release.apk` على فلاشة.
2. بالشاشة: الإعدادات ← الأمان ← اسمح بمصادر غير معروفة لمدير الملفات.
3. افتح الفلاشة من مدير الملفات واضغط على الملف حتى ينصب.
4. اضغط زر الهوم واختار رونق.

ملاحظة: خطوات منع الإعلانات وتعطيل الواجهة الأصلية تحتاج ADB.

## الأمان
- **التحديث:** يقبل بس روابط https من GitHub، ويتأكد من حجم الملف وبصمة SHA-256 قبل التثبيت، وأندرويد نفسه يرفض أي ملف مو موقّع بنفس مفتاحك.
- **مفتاح التوقيع:** مفتاح نشر خاص (RSA ٤٠٩٦) بكلمة سر عشوائية من ٣٢ حرف، ينصنع مرة وحدة بأول install.bat داخل `%USERPROFILE%\rawnaq_keys`، وينحفظ بـ GitHub كـ Secret مشفّر بس. ما ينرفع للمستودع أبداً. **خذ نسخة من مجلد rawnaq_keys على فلاشة**: بدونه ما يتثبت أي تحديث فوق رونق.
- **رمز الأهل:** محاولات محدودة وقفل مؤقت، والتطبيق ينبّهك إذا بعده الافتراضي.
- **المزامنة بالشبكة:** مطفأة افتراضياً، ما تشتغل بالرمز السهل، تنقفل ربع ساعة بعد ٥ محاولات غلط من أي جهاز، وتقبل بس الثيم والترتيب والملفات (لا رابط تحديث ولا رمز ولا إعدادات طاقة).
- **تصحيح الأخطاء بالشبكة (ADB):** install.bat يعرض يطفيه بآخر التنصيب، لأن التحديثات صارت تجي من GitHub.
- **معلوماتك الخاصة:** عناوين شاشاتك (`tvs.txt`) وملفات التنصيب الخاصة بشاشاتك ما تنرفع للمستودع.
